## Import fra Anki

- Input: tekstfil fra Ankis "Notes in Plain Text" (`.txt`), tabulator- eller semikolonsepareret, med de valgfrie hovedlinjer `#separator:`, `#html:`, `#tags column:`, `#deck column:`, `#notetype column:`, `#guid column:`. Også almindelig CSV/TSV uden hovedlinjer.
- HTML i felterne laves om til tekst: `<br>`, `<div>` og `<p>` bliver linjeskift, `<b>`/`<strong>` bliver `**fed**`, øvrige tags fjernes, entiteter afkodes. MathJax `\(…\)` og `\[…\]` bliver `$…$` og `$$…$$`. Billeder (`<img>`) og lyd (`[sound:…]`) fjernes, og antallet vises.
- Brugeren vælger kolonne for forside, bagside og tags, emne og type til alle kort, og ser et eksempel før import.
- Dubletter: et kort med samme `oprindelse` (`anki:<guid>`) eller samme forside springes over.
- Læringshistorik fra Anki importeres ikke i denne fase: kortene starter som nye.
