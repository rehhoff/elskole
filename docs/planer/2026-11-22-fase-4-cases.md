## Case-format

```json
{ "id": "case-…", "titel": "…", "emne": "saer", "intro": "…", "start": "t1",
  "trin": {
    "t1": { "type": "valg", "tekst": "…", "regler": ["r-…"],
            "svar": [ { "tekst": "…", "til": "t2", "point": 2, "feedback": "…", "fejltype": "…" } ] },
    "t2": { "type": "tal", "tekst": "…", "enhed": "A", "facit": 15.88, "tol": 0.3, "point": 2, "til": "t3",
            "loesning": "…", "feedbackRigtig": "…", "feedbackForkert": "…", "fejltype": "…",
            "typiske": [ { "vaerdi": 27.5, "tol": 0.5, "fejltype": "glemt-sqrt3", "feedback": "…" } ] },
    "t3": { "type": "flere", "tekst": "…", "point": 3, "til": "t4", "fejltype": "…",
            "muligheder": [ { "tekst": "…", "rigtig": true, "feedback": "…" } ] },
    "t4": { "type": "slut", "tekst": "…" } } }
```

- `valg`: hvert svar har sit eget `til`, så et forkert valg kan føre til et konsekvenstrin ("hovedsikringen springer"). Et konsekvenstrin er et `valg` med ét svar og 0 point.
- `tal`: tal med komma eller punktum. Rigtigt, når |svar − facit| ≤ `tol`. `typiske` genkender typiske fejl og giver fejltype og forklaring. `rigtigTil`/`forkertTil` kan bruges i stedet for `til`.
- `flere`: point × (rigtige valgt − forkerte valgt) / antal rigtige, mindst 0.
- Tekst vises med `vis()` (KaTeX og **fed**).

## Point og resultat

- Score = opnåede point / mulige point på den vej, brugeren gik (konsekvenstrin tæller 0). `korrekt` = score ≥ 0,8.
- `fejltype` = den første fejltype på vejen.
- Gemmes med `tilfoejResultat({ art:'case', ref:case.id, emne, korrekt, score, fejltype, varighedMs, data:{ vej } })`, hvor `vej` er `[{ t, v, p, m }]` (trin, valg, point, maks.).
- Efter casen vises hvert trin med valget, point, forklaring og links til reglerne.
