# Elskolen

Træning til elektrikerfaget i browseren eller som installeret app: gentagelse med mellemrum (FSRS), kort med kildehenvisninger, formler med KaTeX, backup og synk mellem enheder via en hemmelig GitHub Gist. Virker uden net.

Se `docs/plan.md` for den samlede plan og `CLAUDE.md` for regler og arbejdsgang.
